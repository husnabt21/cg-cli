Research limitations

    
    
      
  1. Token counts are local estimates based on characters ÷ 4, not exact provider token counts.
    2. 
      
  2. Current static graph retrieval primarily targets JavaScript/TypeScript.
    3. 
      
  3. Static analysis may miss dynamic runtime relationships and instance-method calls such as service.create().
    4. 
      
  4. Retrieval operations are not actual internal AI-model tool calls.
    5. 
      
  5. Actual AI tool-call reduction is not measured unless agent transcripts are supplied.
    6. 
      
  6. Response semantic/functional equivalence requires human evaluation or a separately validated evaluator.
    7. 
      
  7. Controlled fixture benchmarks may not fully generalize to real open-source repositories.
    8. 
      
  8. Gold expected-symbol sets produced by the same fixture generator can introduce evaluation bias.
    9. 
      
  9. Adaptive confidence is heuristic and is not statistically calibrated.
    10. 
      
  10. Model behavior differs between Claude, GPT, Gemini, and other systems.
    11. 
      
  11. Real open-source repository evaluation remains future work unless genuinely implemented and tested.
    12. 
    

    
Token counts are local estimates for comparison. Actual token counts vary by model tokenizer, source code, system messages, structured requests, tool schemas, and provider behavior.
